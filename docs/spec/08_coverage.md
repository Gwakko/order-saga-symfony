# 08. Карта покрытия крайних случаев

Таблица ниже сгенерирована `bin/check-edge-case-coverage --markdown` из колонки «Тест» файла `04_edge_cases.md`: идентификатор считается найденным, если в `tests/` или `phpstan/` есть `#[Group('T-...')]` или в `worker-go/**/*_test.go` есть комментарий `// Group: T-GO-NN` (M9.5). `make check-coverage` (входит в `make ci`) падает, если хотя бы один EC ссылается на отсутствующий идентификатор.

Пометки: `ручной` значит, что строка содержит ручную или ревью-часть (EC-81: сигнатура входа workflow проверяется ревью, EC-85: проверка потери соединения с БД полуавтоматическая); автоматическая часть таких строк всё равно обязана быть найдена. `e2e` значит, что среди тестов строки есть такой, чей идентификатор встречается только в группе PHPUnit `go-e2e` (`make test-go-e2e`, вне `make ci`, M9.5: EC-93, EC-97, EC-107). `slow` значит `@group slow`: тест не входит в `make ci`, запускается `make test-slow` (T-I-43, около 15 с).

Скрипт проверяет наличие идентификатора, а не качество теста; качество проверено вручную (выборочный разбор тестов и мутационная проверка пяти критичных EC), результаты в `docs/reports/M8b.md`.

Тесты T-I-10, T-I-40, T-I-42 из спецификации были единственными отсутствовавшими на момент M8.1 и добавлены в M8.1:

- T-I-10 `tests/Integration/Payment/ChargePaymentIdempotencyTest.php`;
- T-I-40 `tests/Integration/Persistence/TimezoneIndependenceTest.php` (выполняется в процессе PHPUnit: переключает `date_default_timezone_set`, `TZ` и часовой пояс сессии Postgres на Europe/Kyiv и сравнивает снимок с запуском под UTC; отдельный процесс из `05_testing.md` не нужен, так как все три настройки меняются на лету);
- T-I-42 `tests/Integration/Persistence/KeyCodeLeakTest.php`.
