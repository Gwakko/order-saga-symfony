## Ответ на Q-M9-6

SDK `v1.52.0` совместим с `temporalio/temporal:1.10.1`: 8 интеграционных тестов (T-GO-20…26) идут против этого образа в compose (`start-dev`), включая таймаут ScheduleToStart, повторы и падение воркера; контейнерный воркер подключается и проходит `CheckHealth`. Несовместимостей не обнаружено.

## Отклонения от спеки

1. T-GO-24: воркер A запускается как процесс (собранный бинарь) и убивается SIGKILL, что точнее «Stop()» из спеки.
2. Для времён попыток история хранит `ActivityTaskStarted` только последней попытки, поэтому `Attempt = 3` / `2` проверяется по этому событию, а не по списку всех попыток.
3. `workerhost.Deps` принимает `Register func(worker.Worker)` вместо активности напрямую (host не знает об use case).
4. `image inspect` показывает `nonroot:nonroot`, а не просто `nonroot`.
5. `go-test-int` сам делает `docker compose up -d temporal`.
6. `go-toolchain` получил `TEMPORAL_ADDRESS` (нужно для интеграции), `go-test` без тега его не использует.
7. Heartbeat не добавлен (решение §4.7).
