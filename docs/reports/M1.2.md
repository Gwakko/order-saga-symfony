# M1.2 Качество: PHPStan max, CS, PHPUnit

## Сделано
- `phpstan.neon`: level max, paths src/phpstan/tests, `checkUninitializedProperties: true`, расширения phpstan-symfony, phpstan-phpunit (extension + rules), phpstan-strict-rules, phpat. Без baseline и `ignoreErrors` (`grep -E "ignoreErrors|baseline" phpstan.neon` пусто). Фикстуры-нарушители исключены через `excludePaths.analyse`.
- `.php-cs-fixer.dist.php`: `@PER-CS`, `declare_strict_types`, `strict_param` (нужен `setRiskyAllowed(true)`), каталоги src, phpstan, tests, gateway-emulator; Fixtures исключены.
- `phpunit.dist.xml`: наборы `unit`, `integration`, `workflow`, `functional`; `failOnEmptyTestSuite="false"`. Группа `concurrency` задаётся атрибутом `#[Group('concurrency')]`, запуск `--group concurrency`, отдельной конфигурации не требует.
- Цели Makefile: phpstan, cs, cs-fix, test-unit, test-int, test-wf, test-func, ci.
- Q10: phpstan-symfony 2.1, phpstan-phpunit 2.1, phpstan-strict-rules 2.1 ставятся без конфликтов с PHPStan 2.3.7. PHPUnit 13.4.8, PHP CS Fixer 3.95.

## Не сделано
- Собственные правила (M1.3), baseline (запрещён).

## Отклонения от спеки
- Рецептные `tests/bootstrap.php` и `src/Kernel.php` приведены под правила (strict_types, PER-CS); `bootstrap.php` переписан без `method_exists`/`mixed` в условии, иначе PHPStan max давал 2 ошибки без возможности их игнорировать.
- `make phpstan` перед анализом прогревает кэш dev (`bin/console cache:warmup`), чтобы существовал `var/cache/dev/App_KernelDevDebugContainer.xml` для phpstan-symfony.
- `.gitignore`: добавлены `.phpunit.cache/`, `.php-cs-fixer.cache`.
- `composer.json`: в `autoload-dev` добавлены `App\PhpStan\Rules\` и `App\PhpStan\Architecture\`.
