# M4.4 Эмулятор платёжного шлюза

## Сделано
- `gateway-emulator/` без зависимости от `src/` и Symfony: `public/index.php` (точка входа `php -S`), `autoload.php`, `src/` (`Handler`, `Store` на SQLite, `Mode`/`ModeKind` enum, `Request`/`Response`). `README.md` только про API.
- Эндпоинты: `POST /charges`, `GET /charges/{key}`, `POST /refunds`, `POST /__admin/mode`, `GET /__admin/stats`; дополнительно `POST /__admin/reset` и `/health`.
- Все 13 режимов: `ok`, `decline`, `delay:<ms>`, `http500`, `http503:<n>`, `accept-then-502`, `truncated-json`, `no-charge-id`, `wrong-currency`, `wrong-amount`, `drop-connection`, `unknown-status`, `late-success:<ms>`. Режимы сбоев действуют и на возвраты (EC-45, EC-46).
- Идемпотентность по `Idempotency-Key` для списаний и возвратов, одно выполнение при повторах и параллельных запросах (SQLite, `BEGIN IMMEDIATE`). Деньги только `int`, float в `amount` даёт 422.
- `compose.yaml`: у сервиса `gateway-emulator` добавлено `environment: PHP_CLI_SERVER_WORKERS: "8"` (без воркеров `php -S` однопоточный и `delay` блокирует остальные запросы). Больше ничего не менялось.
- Тесты: `gateway-emulator/tests/HandlerTest.php` (в процессе, SQLite `:memory:`, управляемые часы) и `HttpTest.php` (по настоящему HTTP, сырой сокет, чтобы видеть обрезанное тело и обрыв). Всего 50 тестов, 522 проверки, каждый режим покрыт в обоих файлах.
- Проверка: `docker compose up -d gateway-emulator && vendor/bin/phpunit gateway-emulator/tests` проходит и на хосте, и в `docker compose exec php`. `HttpTest` берёт адрес из `GATEWAY_EMULATOR_URL`, иначе `gateway-emulator:8081` (в контейнере), иначе `127.0.0.1:8081`.

## Не сделано
- PHPStan и php-cs-fixer на `gateway-emulator/` не настраивались (в спеке для M4.4 не требуется).

## Отклонения
- `drop-connection`: спека не уточняет. Реализовано как «заголовки 200 и 10 байт тела отправлены, `Content-Length` больше фактического, соединение закрыто» (EC-25 «обрыв после заголовков»). Операция при этом выполнена.
- `late-success:<ms>`: `POST /charges` сразу отвечает `status: "pending"`, `GET` возвращает `succeeded` после `<ms>`; в `stats` списание считается выполненным с момента приёма. Для EC-28 (все попытки по таймауту) использовать `delay`, затем читать `GET`.
- `decline` отвечает HTTP 402 с телом `status: "declined"`; на возвраты не влияет. `wrong-currency`/`wrong-amount` меняют сохранённое списание (поэтому `GET` отдаёт то же самое); для возврата проверяется только `amount <= списанная сумма`, валюта возврата не сверяется.
- `http503:<n>`: счётчик общий для списаний и возвратов, после `n` ответов режим сам становится `ok`.
- `GET /charges/{key}` не подвержен режимам сбоев.
- `unknown-status` для возвратов возвращает `status: "weird"`.
- Хранилище: SQLite в `/tmp/gateway-emulator.sqlite` внутри контейнера (не в bind mount ради блокировок), сбрасывается при пересоздании контейнера или `POST /__admin/reset`.

## Что проверить вручную
- Из контейнера: `docker compose exec gateway-emulator wget -qO- http://127.0.0.1:8081/__admin/stats`.
- Клиент саги должен ставить `Idempotency-Key` = `refund-{paymentId}` для возвратов и указывать `chargeId` из ответа шлюза.
- Поведение `drop-connection` у конкретного HTTP-клиента (Symfony HttpClient должен дать транспортное исключение при чтении тела).
